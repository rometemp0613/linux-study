## 복습
- `tail -f`: 실시간으로 추가되는 파일 내용 모니터링 (follow)
- `sort -n`: 숫자 정렬 (-n 없으면 문자열 정렬이라 10 < 2 오류)
- `wc -l`: 줄 수 / `wc -w`: 단어 수 / `wc -c`: 바이트 수

## 오늘 배운 것

### tr - 문자 변환/삭제
- `tr 'a-z' 'A-Z'` → 소문자를 대문자로 변환
- `tr -d '\n'` → 개행 문자 삭제
- `tr -s ' '` → 연속된 공백을 하나로 압축
- 파이프로만 입력 받음 (`echo "hello" | tr 'a-z' 'A-Z'`)

### tee - 파이프 중간 저장
- 파이프 흐름을 유지하면서 파일에도 동시 저장
- `ls | tee output.txt | grep ".md"`

### uniq - 중복 제거
- **반드시 sort 후에 사용** (인접한 중복만 제거하기 때문)
- `uniq -c`: 중복 횟수 표시
- `uniq -d`: 중복된 항목만 출력

### 파이프 조합 실전
- `sort | uniq` 세트로 중복 제거
- `grep "ERROR" | wc -l` 로 에러 줄 수 세기
- `history | tr -s ' ' | cut -d' ' -f3 | sort | uniq -c | sort -rn | head -5`
