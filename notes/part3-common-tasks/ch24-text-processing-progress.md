## 파트 A 정리: cut, paste, join

### cut — 열(column) 잘라내기

| 옵션 | 의미 | 예시 |
|------|------|------|
| `-d` | delimiter (구분자) | `-d:` 콜론 기준, `-d,` 쉼표 기준 |
| `-f` | field (필드 번호) | `-f1` 첫째, `-f1,3` 첫째+셋째, `-f2-4` 2~4번째 |
| `-c` | character (문자 위치) | `-c1-5` 1~5번째 글자 |

- 기본 구분자는 **탭(Tab)**
- 구분자는 **한 글자만** 가능 (`-d"::"` 안 됨)
- 공백 여러 개면 cut으로는 힘듦 → `awk` 사용

### paste — 파일을 옆으로 합치기

- `paste A B` → 두 파일을 옆으로 합침 (탭 구분)
- `paste -d,` → 구분자 지정
- `paste -s` → 한 파일의 줄을 한 줄로 합침
- `paste - - -` → stdin을 3개씩 묶어서 한 줄로

### join — 공통 필드로 합치기

- SQL의 JOIN과 같은 개념
- 두 파일 모두 **정렬 필수** (sort 선행)
- 기본: 첫 번째 필드를 키로 사용
- `-1 N -2 M`으로 키 필드 지정

## 실습 결과 (3/3 정답)

- Q1: `cut -d, -f2,3 employees.csv` — 이름+부서 추출 ✅
- Q2: `tail -5 employees.csv | cut -d, -f2` — 헤더 제외하고 이름만 ✅
  - 시행착오: cat과 tail 순서 혼동 → 파이프 순서가 중요함을 체득
- Q3: `paste -d, -s scores.txt` — 점수를 쉼표로 한 줄 ✅
