# Ch.13: A Gentle Introduction to vi

## vi vs vim

- **vi** = Visual Editor (1976년, Bill Joy)
- **vim** = Vi IMproved (향상된 vi)
- 대부분의 리눅스에서 `vi` = 실제로는 vim 실행

## 핵심: 3가지 모드

```
         ┌──────────────┐
   Esc   │              │  i, a, o 등
  ┌──────│  Normal Mode  │──────┐
  │      │  (기본 모드)   │      │
  │      └──────────────┘      │
  │             │    ▲         ▼
  │          : (콜론) │   ┌──────────────┐
  │             │  Esc│   │ Insert Mode  │
  │             ▼     │   └──────────────┘
  │      ┌──────────────┐
  └─────▶│ Command Mode │
         └──────────────┘
```

| 모드 | 용도 | 진입 |
|------|------|------|
| Normal | 이동, 삭제, 복사, 붙여넣기 | `Esc` |
| Insert | 텍스트 입력 | `i`, `a`, `o` 등 |
| Command | 저장, 종료, 찾기/바꾸기 | `:` |

**원칙: 헷갈리면 `Esc`!**

## 열기 / 저장 / 종료

```bash
vi filename        # 파일 열기
```

| 명령 | 동작 |
|------|------|
| `:w` | 저장 (write) |
| `:q` | 종료 (quit) |
| `:wq` | 저장 + 종료 |
| `:q!` | 저장 안 하고 강제 종료 |
| `ZZ` | 저장 + 종료 (Normal Mode) |

## 커서 이동 (Normal Mode)

### 기본 이동 — hjkl

```
         k (위)
          ▲
h (왼쪽) ◄─┼─► l (오른쪽)
          ▼
         j (아래)
```

### 빠른 이동

| 키 | 동작 |
|----|------|
| `0` | 줄 맨 앞 |
| `$` | 줄 맨 끝 |
| `w` | 다음 단어 (word) |
| `b` | 이전 단어 (back) |
| `gg` | 파일 맨 처음 |
| `G` | 파일 맨 끝 |
| `숫자G` | 해당 줄로 이동 |

## Insert Mode 진입

| 키 | 위치 | 기억법 |
|----|------|--------|
| `i` | 커서 앞 | insert |
| `a` | 커서 뒤 | append |
| `o` | 아래 새 줄 | open line |
| `I` | 줄 맨 앞 | 대문자 = 강화 |
| `A` | 줄 맨 뒤 | 대문자 = 강화 |
| `O` | 위에 새 줄 | 대문자 = 반대 |

끝나면 `Esc`로 Normal Mode 복귀.

## 삭제 (Normal Mode)

| 키 | 동작 |
|----|------|
| `x` | 글자 1개 삭제 |
| `dd` | 줄 전체 삭제 |
| `dw` | 단어 삭제 |
| `d$` | 줄 끝까지 삭제 |
| `d0` | 줄 처음까지 삭제 |
| `3dd` | 3줄 삭제 |

## 복사 & 붙여넣기 (Normal Mode)

| 키 | 동작 |
|----|------|
| `yy` | 줄 복사 (yank) |
| `yw` | 단어 복사 |
| `p` | 커서 뒤에 붙여넣기 |
| `P` | 커서 앞에 붙여넣기 |
| `3yy` | 3줄 복사 |

`dd` + `p` = 잘라내기 + 붙여넣기 (줄 이동)

## 실행 취소

| 키 | 동작 |
|----|------|
| `u` | undo |
| `Ctrl-r` | redo |

## 찾기 (Normal Mode)

| 키 | 동작 |
|----|------|
| `/단어` | 아래 방향 검색 |
| `?단어` | 위 방향 검색 |
| `n` | 다음 결과 |
| `N` | 이전 결과 |

## 찾기 & 바꾸기 (Command Mode)

```
:%s/찾을단어/바꿀단어/g     # 전체 바꾸기
:%s/찾을단어/바꿀단어/gc    # 하나씩 확인하며 바꾸기 (confirm)
```

- `%` = 파일 전체
- `s` = substitute
- `g` = global (줄에 여러 번 나와도 전부)
- `c` = confirm (y/n 선택)
