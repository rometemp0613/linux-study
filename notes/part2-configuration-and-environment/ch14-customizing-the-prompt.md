# Ch.14: Customizing the Prompt

## PS1 — 프롬프트 환경변수

- 프롬프트는 `PS1` 환경변수에 저장
- `echo $PS1`로 현재 프롬프트 확인
- `PS1="값"`으로 즉시 변경 가능 (현재 세션에서만)
- 영구 적용: `.bashrc`에 `export PS1="값"` 추가

## 이스케이프 코드

| 코드 | 의미 | 예시 |
|------|------|------|
| `\u` | 유저명 | `dam` |
| `\h` | 호스트명 (짧은 버전) | `DESKTOP-U33LE6V` |
| `\H` | 호스트명 (전체) | `DESKTOP-U33LE6V.local` |
| `\w` | 현재 경로 (전체) | `~/Documents/project` |
| `\W` | 현재 디렉토리 (폴더명만) | `project` |
| `\d` | 날짜 | `Mon Feb 18` |
| `\t` | 시간 (24시간, HH:MM:SS) | `14:30:25` |
| `\T` | 시간 (12시간, HH:MM:SS) | `02:30:25` |
| `\@` | 시간 (12시간, AM/PM) | `02:30 PM` |
| `\n` | 줄바꿈 | |
| `\$` | `$` 또는 `#` (일반/root) | |

## 색상 코드

형식: `\[\033[코드m\]내용\[\033[00m\]`

| 코드 | 색상 |
|------|------|
| `0;31` | 빨강 |
| `0;32` | 초록 |
| `0;33` | 노랑 |
| `0;34` | 파랑 |
| `0;35` | 보라 |
| `0;36` | 청록 |
| `01;3X` | **굵게** + 해당 색 |
| `00` | 리셋 (색 끄기) |

### 중요 규칙

- `\[...\]`로 색상 코드를 **반드시** 감싸야 함
  - bash에게 "화면에 안 보이는 문자"라고 알려줌
  - 빠지면 긴 명령어 칠 때 줄바꿈/커서 위치 깨짐
- 색 넣은 후 `\[\033[00m\]`로 **리셋** 필수 (안 하면 색이 번짐)

## PS2

- 줄이 이어질 때 나오는 프롬프트 (기본값: `>`)
- 예: `echo "hello` → 다음 줄에 `>` 표시

## 예시

```bash
# 기본 형태
PS1="\u@\h:\w\$ "
# 결과: dam@DESKTOP-U33LE6V:/home/dam$

# 색상 + 시간
PS1="\[\033[01;31m\][\t]\[\033[00m\] \[\033[01;34m\]\w\[\033[00m\]\$ "
# 결과: [14:30:25] /home/dam$ (빨간 시간 + 파란 경로)

# 2줄 프롬프트
PS1="\[\033[01;32m\]\u@\h\[\033[00m\]\n\[\033[01;34m\]\w\[\033[00m\] \$ "
# 결과:
# dam@DESKTOP-U33LE6V    (초록)
# /home/dam $             (파랑)
```
