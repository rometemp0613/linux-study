# 완벽히 암기한 용어/개념

## Ch.1~8 복습 (2026-02-13 승급)

- **cd가 내장(builtin)인 이유**: 외부 프로그램이면 자식 프로세스에서 디렉토리 변경 후 사라짐. 현재 셸 자체의 디렉토리를 바꿔야 하므로 내장 필수
- **큰따옴표 안에서 되는 확장**: `$변수`, `$(명령)`, `$((식))` — $ 계열만. 안 되는 것: `*`, `~`, `{a,b}`
- **`ls -l` 맨 앞 글자**: `d` = 디렉토리, `-` = 일반 파일, `l` = 심볼릭 링크
- **프롬프트 `$` vs `#`**: `$` = 일반 사용자, `#` = root (슈퍼유저)

## Ch.1~8 복습 (2026-02-16 승급)

- **`$()` vs `$(())`**: `$()` = 명령어 치환(명령어 실행 → 출력 결과로 대체). `$(())` = 산술 확장(수학 계산 → 결과로 대체, 정수만)

## Ch.11 복습 (2026-02-16 승급)

- **.bashrc는 비로그인 셸에서 실행**: 로그인 셸 = `.bash_profile`, 비로그인 셸 = `.bashrc`. `.bash_profile`이 `.bashrc`를 호출해서 간접 실행도 됨
- **PATH 추가는 = 재할당**: `export PATH="$PATH:/새경로"`. `>>` 리다이렉션 아님! 변수는 파일이 아니라 재할당으로 수정

## Ch.1~8 복습 (2026-02-17 승급)

- **`2>&1` 순서 문제**: `> file 2>&1` = 둘 다 file / `2>&1 > file` = stderr는 화면, stdout만 file. 핵심: 실행 시점의 stdout 위치를 따라감
- **`-`로 시작하는 파일 삭제법**: `rm -- -file.txt` 또는 `rm ./-file.txt`. 따옴표로는 안 됨 — 따옴표는 셸 확장을 막는 거고, `-` 옵션 해석은 명령어 자체의 문제
- **하드 링크 vs 심볼릭 링크 3가지 차이**: 원본 삭제 시(하드=유지, 심볼릭=깨짐) / 디렉토리(하드=불가, 심볼릭=가능) / 다른 디스크(하드=불가, 심볼릭=가능)
